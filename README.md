#
## A creative portfolio website with motion, sound, and a few surprises.

## Features

- Smooth motion and animations throughout the site
- Sound effects on interactions
- A funny cat with sound
- Project screen recordings that play on hover
- Noise texture overlay
- Rain mode in the footer, with a rain sound that fades in and out
- Responsive layout for desktop and mobile

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Icons

## Getting Started

```bash
git clone https://github.com/ayan-011/YOUR-REPO-NAME.git
cd YOUR-REPO-NAME
npm install
npm run dev
```
## Note on Sound

Browsers block audio until the visitor interacts with the page, so sounds start only after a click or tap.
